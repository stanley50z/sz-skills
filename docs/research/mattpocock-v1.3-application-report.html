Integration review and corrections

Four Opus 5.5 subagents implemented disjoint slices. Further Opus sessions checked preview consistency, reviewed Standards and Spec separately, trialed the retrospective, and applied focused integration corrections.

  • Protect the review branch. Whole-spec cleanup now retains the integration branch and open PR, and removes only task-owned ticket/fix worktrees and their landed branches.
  • Prevent false-green worktrees. Workers must provide dependencies and ignored test inputs securely. Unexpectedly skipped or uncollected required tests fail verification.
  • Give review one owner. TDD defers review-driven refactoring when implement or implement-spec owns review. Whole-spec workers do not launch redundant per-ticket reviews that ask the user for a comparison point; the integrated review remains mandatory.

  • Stop preview servers before handoff. Keeping a comparison file available does not authorize leaving a process running. A temporary server stays up only if the user explicitly requests it.
